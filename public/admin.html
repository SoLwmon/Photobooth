Printing

DNP printer: open Printing preferences → Advanced, set Paper Size: PR (4x6) and 2inch cut: Enable, then OK. ScareBooth picks PR (4x6) for you, but the cut switch lives in the driver. Press Test print — two separate strips should come out.

Reprint any past strip from the gallery. Set paper size and borderless in the printer’s Windows Printing preferences — ScareBooth also picks a 4×6 / 2×6 paper size automatically when the driver offers one.

Press 📏 Alignment test: it prints coloured frames 1 mm apart on every edge. On each edge, read the number of the first frame you can see fully. Top and bottom should match — if the top shows 0 and the bottom 3, the picture is 1.5 mm too low: set Move up/down to −1.5. Same for left/right. If both ends are cut, lower Size to about 97.
